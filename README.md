# Gua brand assets

Logos, app icons, backgrounds and mockups for [Gua](https://gua.global), the private messenger built on Matrix.

## Contents

- `logos/`: the Gua logo on a transparent and on a white background, the logo with the wordmark, and the gua-resolver logo.
- `icons/`: app icons, including 1024x1024 store renders and the Xcode `.icon` bundle.
- `background/`: the welcome background.
- `mockups/`: device mockups used on the website and in README hero images.

## Using the assets

Other Gua repositories reference the files here by raw URL, for example:

```text
https://raw.githubusercontent.com/Gua-ra/gua-branding/main/logos/gua-logo-transparent.png
```

Keep paths stable: renaming or moving a file breaks those references.
